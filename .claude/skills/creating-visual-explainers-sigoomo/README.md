# 図解作成スキル（しごおもラボ トンマナ版）

トピックを渡すと、しごおもラボのサイトに寄せた見た目の**図解HTML**を1枚作ってくれる Claude Code 用のスキルです。出来上がったHTMLはブラウザで開けて、そのままPDFにもできます。

しごおもラボのサイトの見た目に寄せた非公式版です。コミュニティ公式の配布物ではありません。

---

## 1. 入れる

`SKILL.md` と `model-answer.md` の2つを、**同じ名前のフォルダに入れて**、下の場所に置くだけです。

**Windows**

```
C:\Users\<あなたのユーザー名>\.claude\skills\creating-visual-explainers-sigoomo\
├── SKILL.md
└── model-answer.md
```

**Mac**

```
~/.claude/skills/creating-visual-explainers-sigoomo/
├── SKILL.md
└── model-answer.md
```

`.claude` や `skills` フォルダが無ければ、自分で作って構いません。フォルダ名は上のとおりにしてください（`SKILL.md` の先頭に書いてある `name:` と揃える必要があります）。

置いたら Claude Code を再起動します。

---

## 2. 使う

チャットでこう言うだけです。

```
しごおもトンマナで図解して
```

トピックを添えるとそのまま作り始めます。

```
「心理的安全性」をしごおもトンマナで図解して
```

記事や動画のまとめを貼り付けて「これを図解して」でも動きます。その場合は貼った内容が優先され、検索は固有名詞の裏取り程度に絞られます。

出来上がったファイルは、**今開いている作業フォルダの `output/` の中**に `output/心理的安全性.html` のような名前で保存されます。ブラウザにドラッグ＆ドロップすれば表示できます。右上の「PDF」ボタン（または Ctrl+P / Cmd+P）でPDFにもできます。

---

## 3. 中身を読むときの地図

`SKILL.md` は、AIに渡している指示書そのものです。上から順にこうなっています。

| 節 | 中身 |
|---|---|
| `description:`（先頭） | どんな言い方をしたらこのスキルが起動するか |
| トンマナ | 色・フォント・見出しの型の**方針**（日本語で書いた言葉の指示） |
| ワークフロー | Step 0〜6。何を読み、何を調べ、どこに保存するか |
| 守ること（禁止事項） | やってほしくないことの列挙 |
| コンテンツ生成の指針 | どんな図をどう使い分けるか |
| 図解テンプレート | 出力HTMLの「額縁」。色の定義もここ |

`model-answer.md` は完成品の実例です。**ルールではなく実物を見せる**のが、このスキルで一番効いている部分かもしれません。細かい指示を増やすより、良い完成品を1つ見せたほうが、AIは品質を揃えやすくなります。

### 見た目を自分好みに変えたいとき

ひとつだけ先に知っておくと詰まりません。**色を変えるには3箇所を揃える必要があります。**

1. `SKILL.md` の**トンマナ節** — 「何色をどう使うか」の方針
2. `SKILL.md` 末尾の**図解テンプレート** — Tailwind の色定義そのもの（`smo: { ... }` の部分）
3. `model-answer.md` — 実例の中で使われているクラス名（`text-smo-navy` など約400箇所）

1だけ書き換えても見た目は変わりません。テンプレートに定義が無い色名は、ブラウザ上でただ無視されるからです。AIに頼むときは「この3箇所を揃えて」と伝えると一度で通ります。
